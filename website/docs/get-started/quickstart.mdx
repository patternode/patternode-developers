# Quickstart

Two calls: who am I, then the demonstration series. They work with a test key, which costs nothing, and with no key at all against the mock.

## 1. Choose where to call

| Target | Base URL | Key |
|---|---|---|
| The mock, on your machine | `http://127.0.0.1:4010` | Any key of the right shape, e.g. `pnk_test_` and 36 `A`s |
| Production | `https://api.patternode.com` | Your test key, from the welcome email ([Getting your API keys](api-keys.md)) |

To run the mock, from the repository root (Python 3.10 or newer, nothing to install):

```bash
python mock/mock_patternode.py
```

## 2. Make the calls

```bash
export PATTERNODE_BASE_URL=http://127.0.0.1:4010
export PATTERNODE_API_KEY=pnk_test_AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
```

## 3. Read the answer

A segmentation is a list of segment boxes, parents before children. Each has a level (`height`), the bars it covers, and its open, high, low and close with their times. The open right edge at each level is `provisional`. [Shards and bars](../concepts/shards.md) explains them; the [API reference](/api/patternode-api) has every field.
